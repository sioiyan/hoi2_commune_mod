# HOI2 マルチプレイ用 Mod 管理リポジトリ

こちらは、身内での **Hearts of Iron II (HOI2)** マルチプレイのために使用する **Mod** を管理するためのリポジトリです。

=======
## 使用方法
`commune_multi`ディレクトリを`Mods`ディレクトリ内に入れてください。


## ⚠️ 編集時の重要事項 (文字コードの維持)

特に、イベントファイルやテキストデータなど、各種テキストファイルを編集する際は、以下の **文字コードに関するルールを厳守** してください。

| 項目 | 設定 | 必須 |
| :--- | :--- | :--- |
| **文字コード** | **Windows-1252** | **必須** |

**Windows-1252** 以外の文字コードで保存すると、文字化けが生じ予期せぬエラーが発生する恐れがあります。

### 推奨されるエディタ設定

* 使用するエディタ（VS Code、サクラエディタなど）で、ファイルの保存時にエンコーディングを **`Windows 1252`** に設定・維持して作業を行ってください。

---

ルールを守って、楽しいMOD開発にしましょう！
